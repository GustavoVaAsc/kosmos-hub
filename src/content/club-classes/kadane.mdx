<div class="club-section">
    <h2>The Problem</h2>
    <p>
        Given an array of integers, find the contiguous subarray
        (containing at least one number) which has the largest sum
        and return its sum.
    </p>
    <p><strong>Example:</strong></p>
    <CodeBlock
        code={`Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4]\nOutput: 6\nExplanation: [4, -1, 2, 1] has the largest sum = 6`}
        language="text"
    />
</div>

<div class="club-section">
    <h2>The Algorithm</h2>
    <p>
        Kadane's algorithm works by iterating through the array and at
        each position deciding whether to:
    </p>
    <ul>
        <li>
            Extend the current subarray by including the current element
        </li>
        <li>Start a new subarray from the current element</li>
    </ul>
    <p>
        We keep track of the maximum sum seen so far and update it
        whenever we find a larger sum.
    </p>
</div>

<div class="club-section">
    <h2>Variations &amp; Extensions</h2>
    <ul>
        <li>
            <strong>2D Kadane:</strong> Maximum sum rectangle in a 2D matrix
        </li>
        <li>
            <strong>Circular Array:</strong> Maximum subarray sum in a circular
            array
        </li>
        <li>
            <strong>With Indices:</strong> Return the start and end indices
            of the maximum subarray
        </li>
        <li>
            <strong>K Subarrays:</strong> Maximum sum of K non-overlapping
            subarrays
        </li>
    </ul>
</div>

<div class="club-section">
    <h2>Complexity Analysis</h2>
    <ul>
        <li>
            <strong>Time Complexity:</strong> O(n) - single pass through the
            array
        </li>
        <li>
            <strong>Space Complexity:</strong> O(1) - only using constant
            extra space
        </li>
    </ul>
</div>
